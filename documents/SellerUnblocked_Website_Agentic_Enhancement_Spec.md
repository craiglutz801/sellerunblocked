# SellerUnblocked Website — Additive Agentic Enhancement Spec

## Purpose

Evolve the current SellerUnblocked marketing website to make the AI / agentic capability unmistakable **without disturbing the core story, visual system, or header that already works.**

This is an additive enhancement — not a redesign.

The current product narrative is strong:

> **Find the friction. Fix the system. Help every seller win.**

The new layer should make one additional promise:

> **SellerUnblocked does not just surface the signal. It helps leaders and sellers act on it.**

Use AI and agents as the action layer beneath the existing "diagnostic spine" concept. Do not make the site sound like a generic AI chatbot, an autonomous sales-rep replacement, or a performance surveillance system.

---

## Non-negotiable guardrails

1. **Keep the header nearly unchanged.**
   - Preserve logo, nav order, CTA styling, page spacing, and current visual identity.
   - Do not add a top-level `AI Agents` header item by default.
   - Do not add flashy AI gradients, robot imagery, or generic chatbot visuals.
   - Optional: add a subtle `AI-powered action layer` micro-label inside existing product-related content only.

2. **Preserve the current hero.**
   - Keep the current eyebrow, headline, structure, main bullets, CTA pair, and the dashboard / kit mockup.
   - Do not replace the hero headline with an “AI” headline.
   - AI should make the existing promise more credible, not become the entire story.

3. **Preserve the central positioning.**
   - SellerUnblocked is still a **Revenue Organization Intelligence** platform.
   - The platform is still centered on seller feedback, diagnostics, leadership intelligence, and private enablement kits.
   - The agentic layer is what converts insight into useful action.

4. **Protect seller trust in every mention of AI.**
   - Never imply that an AI agent ranks sellers, evaluates performance, recommends PIPs, or exposes private feedback to managers.
   - Reinforce: leadership sees aggregated patterns; sellers get private support.

5. **Use the current design system.**
   - Reuse existing typography, dark navy surfaces, bright blue CTA treatment, cyan/teal accents, rounded card shapes, shadows, grid spacing, and animation language.
   - New UI should look like it was always part of SellerUnblocked.

## Strategic narrative update

### Existing story

```text
Seller feedback → diagnostic spine → leadership intelligence + personalized seller kit → improvement
```

### Enhanced story

```text
Seller feedback + approved company knowledge
        ↓
SellerUnblocked diagnostic spine
        ↓
AI action layer
        ↓
Leadership agents help fix the system
Seller agents help reps act in the moment
        ↓
Measure what improves
```

### New positioning language

Use this sparingly across the page:

> **SellerUnblocked combines revenue-organization intelligence with an AI action layer — helping leaders turn friction into operational priorities and giving sellers private guidance they can use in the next deal.**

Supporting alternatives:

- **Insight tells you what is wrong. Agents help move the work forward.**
- **One diagnostic system. Intelligence for leadership. Practical help for every seller.**
- **From seller signal to system action — and from friction to forward motion.**
- **AI that works on the seller’s side, not against them.**

Avoid overusing the word `agentic`. Use it in one strategic section and perhaps one product capability label. In customer-facing copy, "AI action layer," "AI-guided," and "private seller coach" are usually clearer.

**Body:**


### Card 3: AI action layer

**Label:** `AI action layer`

**Body:**

```text
Guides investigation, recommends next steps, and activates the right support.
```

**Visual:** use an abstract spark / connection / path icon. No robot icon.

**Label:** `For leadership`

**Headline:** `Move from dashboard to decision.`

**Body:**

```text
Agents investigate friction, assemble the evidence, propose actions, and help track whether interventions are working.
```

**Small examples:**

- Action plan and owner
- Executive update
- Intervention measurement

### Branch card: Seller help

**Label:** `For sellers`

**Headline:** `Move from feedback to forward motion.`

**Body:**


**Small examples:**

- Prepare for a CFO call
- Find the right playbook
- Practice a pricing objection
- Use a proposal-stage checklist

Place below the visual:

- On desktop, branch cards gently lift on hover.
- Hovering a branch softly highlights the related pathway from `AI action layer`.
- No autoplay animation required.
- On mobile, use a vertical stacked flow with a clear divider between leadership and seller paths.

# Visual System Requirements

## Colors

Use existing tokens from the current site. Do not introduce a new "AI palette."

Suggested role assignment only:

- Existing navy: main background and high-contrast panels
- Existing electric blue: CTA and primary action pathways
- Existing cyan / teal: signal and agentic connectors
- Existing violet / purple: optional secondary highlight for seller-side coaching modules
- Existing white / soft slate: content panels and readable surfaces

## Icon direction

Good:

- spark / pathway
- layered nodes
- magnifier + signal
- action checklist
- resource compass
- role-play speech bubbles
- connected dots

Avoid:

- robots
- humanoid avatars
- brain illustrations
- generic "AI magic" stars everywhere
- overdone glowing circuit art

## Motion

Use subtle existing motion conventions.

- Connector line draw on scroll: acceptable, 400–700ms
- Card lift on hover: acceptable
- Pulse on signal nodes: minimal and infrequent
- Typing simulation in seller coach mockup: optional, only if motion respects reduced-motion preferences

No infinite looping animations that make the page feel like a crypto site or a generic AI startup.

# Acceptance Criteria

The update is successful only if all of the following are true:

- The header and hero still feel essentially unchanged.
- A first-time visitor still understands SellerUnblocked before encountering agent language.
- The page clearly shows that AI helps both leadership and sellers act.
- The agentic story is contextual and specific, not generic AI marketing.
- Seller privacy is clearer, not muddier.
- Enablement kits feel more dynamic and immediately useful.
- The current design system remains dominant.
- No section feels crowded, repetitive, or more visually aggressive than the existing hero.
- The core summary remains easy to say out loud:

```text
SellerUnblocked finds the friction, helps leadership fix the system, and gives every seller private, AI-guided support to win inside it.
```

# Final Creative Direction

The website should not become:

```text
“Here is our AI platform.”
```

It should become:

```text
“Here is a better way to listen to sellers — and an AI-backed way to help people act on what they tell you.”
```

The best visual and narrative outcome is that a CRO sees operational leverage, an enablement leader sees relevance and content utilization, and an IC seller sees an ally that might actually help with the next deal.
